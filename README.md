# SPARK / شرارة — MASTER V2.0
> **منصة الأنشطة والتفاعل الجماعي الفورية**  
> *"أشعل البداية.. عندك مجموعة؟ عندك شرارة."*

---

## 1. ما هي شرارة؟ (What is SPARK?)
**شرارة (SPARK)** هي منصة تفاعلية حية لتيسير الأنشطة وكسر الجمود للمجموعات وورش العمل واللقاءات الشبابية والأسرية والتعليمية.
الهدف الأساسي منها هو الإجابة الفورية للميسر أو القائد أو المعلم على سؤال:  
**"شن نديروا توا مع المجموعة؟"**

تمكن المنصة المضيف من:
1. استكشاف وتحديد النشاط المناسب وفق معايير المجموعة (الوقت، الطاقة، العدد، الأجهزة).
2. فتح غرفة تفاعلية بلمسة زر وتوليد رمز سداسي وكود QR فوري.
3. انضمام المشاركين مباشرة من هواتفهم بدون تسجيل حساب ولا تحميل تطبيقات.
4. إدارة الجولات والتصويت اللحظي ومشاهدة النتائج التفاعلية مباشرة على شاشة العرض.
5. إطلاق نشاط آخر فوراً لنفس المجموعة ("🎲 شرارة ثانية").

## 2. المكدس التقني (Tech Stack)
- **Framework:** Next.js 14 (App Router) + React 18 + TypeScript
- **Styling:** Tailwind CSS + Vanilla CSS (Light-First Design System)
- **Typography:** Tajawal / Cairo (Modern Arabic Web Typography)
- **Realtime Live Sessions:** Firebase Realtime Database (معزول كلياً عن أي مشاريع Supabase سابقة) + محاكي محلي ذكي (Local Simulation Engine)
- **QR Generation:** Node `qrcode` + Dynamic LAN/Public Runtime Resolver
- **Sound Effects:** Web Audio API Native Synthesizer (بدون اعتماد على ملفات خارجية بطيئة)
- **Deployment:** GitHub + Vercel (Free-Tier Ready)

## 3. حل مشكلة QR والانضمام المباشر (QR Root Cause Fix)
### المشكلة السابقة:
1. كان كود QR يشفر تلقائياً الرابط المحلي `http://localhost:3000/join?code=...`؛ مما يؤدي عند مسحه بكاميرا الهاتف إلى فشل الاتصال لأن الهاتف يطلب الاتصال بجهازه نفسه وليس بجهاز المضيف.
2. كان تخزين حالة الغرفة يعتمد على `localStorage` و `BroadcastChannel` فقط المحصورة داخل متصفح الحاسوب.

### الحل المعتمد في V2.0:
1. **Dynamic Runtime LAN Resolver (`src/lib/get-join-url.ts` + `src/app/api/network-ip/route.ts`):**  
   في وضع التطوير المحلي، يستعلم المضيف عن عنوان IP الداخلي للحاسوب على شبكة الواي فاي (مثل `http://192.168.1.15:3000/join?code=123456`) ويضمنه في كود QR، ليعمل المسح بكاميرا الهاتف المحمول المتصل بنفس الشبكة مباشرة بنسبة 100%.  
   وفي بيئة الإنتاج (`Vercel` أو أي نطاق مخصص)، يستخدم الرابط العام المباشر تلقائياً بدون أي برمجة صلبة.
2. **عزل وتزامن الجلسات الحية عبر Firebase Realtime Database:**  
   تزامن فوري بين شاشة المضيف وهواتف المشاركين عبر قواعد بيانات Firebase مع الحفاظ على استقلالية تامة عن أي مشاريع Supabase سابقة.

## 4. تصميم الواجهة: Light-First
تمت إعادة هيكلة النظام البصري للمنصة بالكامل ليكون **Light-First**؛ مريحاً للعين، هادئاً، وبطابع عصري يناسب الشاشات الكبيرة والعرض عبر البروجكتر:
- أسطح دافئة ومريحة: `#F8F9FA` و `#FFFFFF`.
- تباين عالي للنصوص: `#0F172A` و `#334155`.
- لمسات لهب برتقالية معتدلة غير صاخبة: `#FF5722` و `#F97316`.
- بطاقات نظيفة بظلال ناعمة وتدرجات مدروسة.

---

## 5. هيكلية المحتوى وبنوك الأسئلة (Content Engine)
تتضمن النسخة 93 نشاطاً متكاملاً مع بنوك أسئلة موثقة:
- **أنشطة الكبار والشباب (Adult / General):**
  - هذا أو ذاك (This or That) — بنك يضم 30 خياراً حاسماً وفكاهياً.
  - تحدي النباهة السريع (Quick Quiz) — أسئلة معرفية متدرجة.
  - حقيقتان وكذبة، سحابة الكلمات، قصة بالإيموجي، النار السريعة، وغيرها.
- **القسم الإسلامي والقيمي (Islamic & Values):**
  - أكمل الآية القرآنية (مع التحقق الدقيق من نص الآية وتوثيق اسم السورة ورقمها).
  - مواقف وقيم إسلامية (مواقف واقعية تفاعلية حول الصدق، العفو، الأمانة، والتعاون).
  - دقيقة معرفة إسلامية وسيرة نبوية موثقة.
- **تحديات اللغة العربية وفصاحتها (Arabic Language):**
  - أضداد، جموع، مفردات قرآنية، أمثال شعبية وفصيحة، بلاغة مبسطة.
- **عالم الأطفال الآمن (Kids Safe Mode):**
  - فئات عمرية مخصصة: (4–6) و (7–9) و (10–12).
  - بيئة آمنة 100% بدون تسجيل حسابات، أسماء مستعارة فقط، وبدون غرف محادثة خاصة.
  - خمن الحيوان، خمن الصوت، تماثيل متجمدة، وتحديات ألوان.
- **أنشطة بدون هواتف (Non-Phone Facilitation):**
  - أدلة توجيه خطوة بخطوة للميسر مع مؤقت 60 ثانية مدمج وخاصية الكلمة السرية للمتطوع (مثل: الشاريدز الصامت، ابحث عن شخص تنطبق عليه العبارة، وتحدي الدقيقة).

## 7. إعداد Firebase Realtime Database
1. أنشئ مشروعاً مخصصاً جديداً في [Firebase Console](https://console.firebase.google.com/).
2. فعّل خدمة **Realtime Database**.
3. ضع القواعد الأمنية التالية للجلسات المؤقتة:
```json
{
  "rules": {
    "spark_rooms": {
      "$roomCode": {
        ".read": true,
        ".write": true
      }
    }
  }
}
```
4. انسخ بيانات الاعتماد إلى ملف `.env.local` كما هو موضح في `.env.example`.

> **ملاحظة:** التطبيق يعمل محلياً بكفاءة تامة حتى بدون إعداد Firebase بفضل محاكي الجلسات الذكي ومحاكي الـ Demo المدمج.

## 8. اختبار تجربة الـ Demo الحية
1. اضغط على زر **"جرّب Demo حي"** في الصفحة الرئيسية.
2. ستفتح غرفة محاكاة ينضم إليها 8 مشاركين افتراضيين بأسماء وصور مميزة.
3. اضغط **"ابدأ التجربة"** (أو اضغط زر المسافة Space).
4. شاهد تصويت المشاركين في الوقت الفعلي وتحديث المخططات البيانية وانتقال الجولات تلقائياً.

---

## 9. اختبار مسح كود QR من الهاتف المحمول
1. شغّل التطبيق محلياً وتأكد من اتصال هاتفك وحاسوبك بنفس شبكة الواي فاي.
2. ادخل كـ Host وأنشئ غرفة لأي نشاط.
3. يظهر كود QR ورابط شبكة LAN تلقائياً (مثل `http://192.168.x.x:3000/join?code=...`).
4. افتح كاميرا هاتفك وامسح الكود.
5. ستفتح صفحة `/join` بالرمز معبأ تلقائياً.
6. اكتب اسمك المستعار واضغط "انضم الآن"؛ ستجد نفسك متصلاً بشاشة المضيف فوراً.

## 10. النشر على Vercel (Deployment)
1. ارفع الكود إلى مستودعك على **GitHub**:
```bash
git add .
git commit -m "feat: SPARK Master V2.0 light-first release"
git push origin main
```
2. ادخل إلى [Vercel](https://vercel.com/) واختر **Import Project** من GitHub.
3. أضف متغيرات البيئة من `.env.example` في إعدادات المشروع بـ Vercel.
4. اضغط **Deploy**. سيعمل الرابط العام ورموز QR تلقائياً عبر نطاق Vercel المباشر.
